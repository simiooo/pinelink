# Native local · v35

22 editable frames: 20 native states and two Web browser-compatibility recovery views. The latter distinguish missing cryptography from storage denial and provide the Android release as an alternative. All frames were saved, reopened and exported in OpenPencil; live rendering verified the Nunito labels after reshaping imported text.

SIM-958 extends the delivered v34 local protocol into Flutter/Android. Native Bonjour/NSD adds nearby discovery; untrusted discovery never creates a pair. Both sides still compare and confirm. Manual QR/package exchange interoperates with Web and remains available when multicast or permissions are unavailable. Codes expire; camera denial returns to package entry.

The graph stays mounted through local sheets. Two endpoints and one delivery-ACK curve; no cloud node or upload ledger. Sheen runs only during live unpaused transfer and stops for disconnection, verification, background suspension and reduced motion. Nearby discovery and reconnect use the shared spinner; errors settle once. 48px targets, white/gray, #0866FF, Nunito and semantic 4px spacing continue v34/v29.

Only account state changes in response to sign-in; the independent local runtime, keys, transfers and graph remain alive. Local entry never waits for a center request. Saved files/history use a full-screen phone view, four status tabs and small icon badges. Detail and consent text is locally left aligned. Permission errors expose code fallback; no technical server form appears in the official experience.

Preview QR patterns are inert. The launcher letter is a product icon, never a replacement for the local-device phone glyph. Native CLI TLS remains separate; this UI uses the same data-only RTC wire protocol as Web. Android release, simulator transfer, permission and lifecycle evidence are required before delivery; Flutter Web or CLI cannot replace those checks. No iOS package is distributed.

Primary sources: [Flutter archive](https://docs.flutter.dev/install/archive), [flutter_webrtc](https://pub.dev/packages/flutter_webrtc), [Bonsoir](https://pub.dev/packages/bonsoir), [mobile_scanner](https://pub.dev/packages/mobile_scanner). Official stable/tag refs both resolve to the installed Flutter 3.47.9 revision; use bundled offline scanner models.
