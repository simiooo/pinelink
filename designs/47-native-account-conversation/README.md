# Android account and visitor conversations v47

The 320 px and 390 px designs extend the accepted device conversation with account and visitor identity badges. The same physical device may appear as distinct account, visitor or local identities. Online invitations use the signed-in account; already paired visitor and local devices and their ongoing work remain available. Signing out removes account conversations from the visible workspace while preserving their encrypted local history.

Files, normal text and concealed sensitive text use the same conversation, per-transfer receive confirmation, Markdown and explicit copy. The sensitive switch applies to newly composed text. This OpenPencil design was saved, reopened and rendered for review; it does not claim the Android implementation is complete.
