## 过渡与动效

| 事件 | 表现 | 完成条件 |
| --- | --- | --- |
| 中心不可达 | 云不可用小标120ms淡入，LAN节点位置不跳动 | 实际探测结果 |
| 本地保存 | 保存按钮保持尺寸；不可发送，微标低干扰活动 | 文件/manifest持久提交 |
| Ready→Queued | 本机/文件时钟标记160ms淡入，队列不播放传输流光 | 本地意图事务提交 |
| Queued→传输 | 真实路线可用后淡入曲线；蓝灰来自真实确认量 | 权限/握手及字节确认 |
| 传输中 | 沿用v20的1.8s流光，仅位于已确认蓝色前缀 | 真实传输活动 |
| 无路线/取消待确认 | 流光80ms退出，已确认蓝色保留 | 实际I/O停止；未伪造远端回执 |
| 本地未发出意图取消 | 条目160ms退出，再220ms重排 | 取消事务与该意图引用释放，保留独立本机文件 |
| 结果未知/冲突 | 保留条目，微标替换；二级页给短原因/下一步 | 有效操作回执或用户决定 |

桌面浮层160ms、移动页面220ms，4px以内淡入位移；退出逆序，焦点回到来源节点/操作。减少动态效果时去掉旋转/流光/位移，直接展示真实状态；可访问状态只在语义变化时播报，不按字节不断宣读。关闭取消待确认详情不会删除该意图。
