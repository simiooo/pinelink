# Unified device connection v43

The main connection surface has one show/enter choice. The app chooses an online invitation when the service is available and offers an offline connection if it is not. A deliberate offline action remains available when one device has no service. One input accepts a short code, invitation link or local connection package, with scan and file import; local comparison and explicit confirmation remain intact.

The OpenPencil `.fig` was saved and reopened with the core engine, then rendered at 320 px, 390 px and desktop widths. It covers online, offline, input and local identity verification states. Rendered frames are design artifacts, not implementation or deployment evidence.
