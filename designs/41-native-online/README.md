# Native online guest v41

Draft extending v30's visitor pairing and v40's Message/Bubble conversation
to Android. Frames cover online invitation, code entry, pairing consent,
per-transfer text consent, progress, disconnection and mixed history. Nearby
and online connections remain separate; neither implies consent to receive.

The `.fig` was created, saved, reopened and rendered using OpenPencil core.
These images are design previews and do not claim that the online native
feature is implemented or deployed.
