# Restored text history v53

Two saved/reopened OpenPencil frames reuse the existing Message/TextBubble style in the global Files/Sent view. Text remains Markdown with Copy; sensitive text is masked by default. A short peer label identifies the source. File attachments retain file tiles. Device conversations keep the same text presentation after reopening.

History repair uses authenticated text manifests and existing encrypted content, never filename extensions. It preserves identities, peer records, plaintext file attachments and transfer completion states. Incomplete/unreadable text stays a message with an unavailable status. One bad history record cannot become a service-wide network error; genuine roster/session failures retain a visible retryable error and automatic bounded recovery.
