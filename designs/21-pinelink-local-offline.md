# Pinelink v21：本地离线补充

基于已验收v20增加两个OpenPencil页面，原有v20页面保留。新增界面待产品验收；此次只实施原生协议/CLI，未跳过验收实施Web/Flutter界面。

- `20 / Local network`：桌面自动发现、桌面/手机直传、手机无设备/权限关闭、本地送达详情、交互与动效契约。
- `21 / Offline pairing`：桌面/手机连接码、桌面modal与手机bottom sheet比较码。

蓝色沿用`#0866FF`。移动端品牌20px、正文14px、上下文12px；20px页面边距，触控容器48px。按语义区分12/16px组内和24/32px组间间距；密集字段局部左对齐。

发现的设备直接进入节点图，不要求先扫码。首次连接在二级界面建立信任；本地可达节点不因互联网断开而降低透明度。配对背景没有进度线，未经接收同意不显示已传输量。本地完成没有云标记或云恢复入口。

动效：设备160ms进入/120ms离开，modal160ms、sheet220ms；传输1600ms流光限制在真实蓝色确认段内，暂停/校验/终态停止。减少动态效果时展示静态进度。OpenPencil保存的是状态与动效契约，实际跨端动画仍由后续界面单元实现。

参考IoT流程：mDNS已进入原生核心；BLE辅助发现、标准安全配对及已配对设备自动地址更新/重连是后续原生适配方向，尚未实现。六位比较码不能作为公开发现凭据。
