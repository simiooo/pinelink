# Account and visitor conversations

The existing node graph and conversation surface are shared by account, visitor and local connections. A small checked account badge distinguishes an account connection; the badge has a tooltip and accessible name. A device can appear separately under different identities, with each history and key kept in its own scope.

An online connection created while signed in uses the account identity. Local connection continues to use the local identity. Signing in or out must not interrupt a visitor transfer; account nodes and account content disappear from the current view on sign-out, while encrypted local records remain isolated for the same account to reopen.

The conversation retains the existing file and Markdown bubbles, explicit receive consent, sensitive switch and copy action. No extra account/visitor mode selector is added.

The OpenPencil file was saved, reopened and rendered at 320 px, 390 px and desktop widths. The four PNG and SVG frames are design evidence, not runtime results.
