# Pinelink 18 · 语义间距、局部左对齐与状态徽标

主稿：`../18-pinelink-semantic-spacing.fig`。这是设计改稿，未实施应用代码。

本轮读取并审查原 15 页全部 107 个顶层画板，重建其中 98 张产品状态画板；复查原 12 个组件，修正节点标签、组件边界和规范页；新增语义规则与徽标说明两张画板。最终共 16 页、109 个顶层画板，原组件保留。

## 间距按关系分配

| 关系 | 间距 |
|---|---:|
| 同一对象的补充信息，如文件名与数量、进度与速率 | 4px |
| 图标与名称、标题与必要原因 | 8px |
| 横向图标与所属文字 | 12px |
| 历史标题与 tabs（同一视图语境） | 16px |
| 标题组与文件信息、文件信息与量化数据 | 24px |
| tabs 与文件网格、网格行、内容与操作区 | 32px |

历史浮层左右 16px、上下 24px；普通桌面弹层左右 20px、上下 24px；手机内容左右 16px，底部 sheet 顶部 40px、底部 48px。容器根据内容高度计算，删除固定空白占位。

文字密集区使用局部左轴：历史每列中的图标与文件名、弹层内的文件身份、说明与字段分组均左对齐。节点图的设备标签围绕圆心居中，数值配对保留各自对齐方式。

## 历史与 tabs

标题只保留设备名，删除副标题。手机导航直接显示设备名，不再在正文重复标题。PC tabs 按内容自适应宽度，标签左右内边距 12px，tab 间距 8px；手机内边距 8px、tab 间距 0，保持 48px 高度。选中下划线跟随标签文字宽度。

文件只显示图标与单行文件名。图标盒 48px，名称间隔 8px，条目高 76px，网格行间隔 32px。状态第三行删除；可复用本机、可复用云副本、一次性、过期均用图标右下角 16px 徽标（12px 图形）表达。过期文件图标减淡，文件名仍保持可读。

## 提示与信息保留

悬停或键盘聚焦显示简短状态提示；过长文件名同时给出完整名称。手机点击条目进入详情，不依赖 hover。提示与可访问名称包含可用性和来源；不会因隐藏状态行失去操作能力。

节点图的暂停、排队、连接、校验和送达同样使用小徽标，并从节点进入详情。真实进度蓝灰弧长与蓝色内部 1600ms 流光保留。错误原因、取消确认、授权/保留决策和拖拽投放指引继续用必要短文案。

## 覆盖与证据

- `source-audit.json`：改稿前全部 107 画板的结构、文字与位置快照。
- `manifest.json`：98 张状态画板与按钮布局。旧 ID 是基线证据；再次编辑时必须重新按页面、名称读取当前 ID。
- `semantic.tokens.json`：按语义命名的间距、徽标与 tab 变量。
- `audit-results.json`、`openpencil-verification.json`：覆盖范围、原生按钮、全页字体、可访问性与保存重开检查。
- `motion-verification.json`：15 项浏览器验证，包含真实 hover 提示、键盘和 320 / 390 / 736 / 1024 四种宽度；另遍历剩余 16 个场景入口。
- `18-history-native.png`、`18-sheet-native.png`：OpenPencil 实际导出；`preview-*.png` 为可操作预览证据。
