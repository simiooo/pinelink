# Native visitor v45

The native unified visitor design extends v44 with an explicit nearby-device entry, a notification row for a connection request and a reconnect action for offline local peers. It retains the same online/local trust boundaries, two-sided local verification and per-transfer receive consent.

The OpenPencil document was saved, reopened and rendered at 320 and 390 px. These are design artifacts; the native implementation and Android release remain tracked by SIM-936.
