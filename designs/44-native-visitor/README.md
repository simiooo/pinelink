# Native visitor v44

Native visitor screens carry forward the unified device conversation and sensitive-text switch from v42 and the unified connection flow from v43. The set covers 320 px and 390 px device actions, messages and attachment draft, online and offline invitations, local verification, per-transfer consent and a three-node cloud route with independent progress segments. It does not replace the platform's system permission or file picker surfaces.

This OpenPencil document was saved, reopened and rendered with the core engine. These frames are design artifacts; native online visitor delivery remains tracked by SIM-936.
