# 动画、语义与生命周期契约

状态拥有事实，动画表现变化。`catalog.json` 为109个目标逐项指定配方、触发权威、时长、中断和减少动态效果；本提案不靠动画结束推进业务状态。

## 节奏和形状

| 层级 | token | 用途 |
| --- | --- | --- |
| 按压 | 80ms | 视觉层 1→.97；48px命中区域、文字布局不缩小 |
| 状态 | 120ms | 图标/描边/颜色；无颜色、透明度或进度超调 |
| 局部控件 | 160ms | 标签、菜单、短反馈；tooltip 先有350ms明确悬停意图 |
| 浮层 | 220ms | sheet 24px靠近，关闭160ms；modal 160/120ms |
| 页面 | 280ms | 父子方向16px，返回反向；草稿和列表身份保留 |
| 空间弹性 | 约360ms | 按钮回位、节点选择、drop接近；m=1、k=420、c=34，从当前位姿和速度重定目标 |
| 活动流光 | 1800ms | 仅当前可见的活动连接，一条蓝色确认段内的局部流光 |

这些是 Pinelink 提案参数，不是 Meta 的内部设计 token。颜色为 `#0866FF`，白灰背景、Nunito、语义间距、局部左对齐保持一致。标签、验证码、文件名、输入光标和正文稳定。系统键盘、文件选择、安装和相机授权由平台处理。

## 传输与云路径

主图两个节点、一条贝塞尔曲线。灰色是未确认量，蓝色边界由当前传输腿的真实确认账本决定。更新最多120ms有界插值，数字和辅助技术值立即更新；同一账本不回退、不超过真实确认量。流光裁在蓝段内，不表示百分比。暂停确认后流光停止，迟到且有效的 ACK 可以静态修正边界；恢复与直连/中继切换不重置确认量。

上行暂存、接收下载、最终校验/持久提交/回执是独立事实。云节点只表示实际云腿，Stored 不等于 Delivered。100%字节可以仍待校验回执，不能硬造99%或通过动画超时展示送达。详细数字、暂停/取消和路线在 modal/bottom sheet。接入时传输 ID、服务/账号 profile epoch、route epoch 和 receipt event ID 必须进入权威校验与去重，动画 owner 不能修改它们。

## 拖拽、列表和输入

有效节点及周围24px作为候选范围；多目标距离相近（小于8px优势）时不擅自选择。仅一个目标 halo，跨节点从当前状态切换。进入子元素不得触发离场；离开范围、Escape、dragend、不可用类型或空 drop 立即清除资格。drop 时重新计算当前位置，不能复用上一目标。系统拖拽图像不叠加第二个伪游标。放下只打开本地 review，不表示上传或接收已确认；触控/键盘可走发送动作和系统文件选择。

文件历史按稳定 key 保留现有元素和选择，只对位置变化做 FLIP；新条目最多3个、24ms间隔、总延迟不超过48ms。筛选不让整个网格闪换；过期/一次性/可复用以角标与tooltip表现，正文密集部分左对齐。输入值、IME组合、文本草稿和密码字符不随动画重建或旋转。复制成功必须等 Clipboard promise；失败保留可选择原文。Google 不要求先填邮箱，不对品牌按钮做缩放或标志变形。

## 减少动态效果、焦点和取消

跟随 `prefers-reduced-motion` / Flutter `MediaQuery.disableAnimationsOf`，运行中切换立即停止位移、缩放、spring、stagger与循环，保留静态选择、进度、运行/暂停语义与错误。WCAG 2.3.3 是 AAA 参考，不声称由此完成全部可访问性认证。预览中的 Full/Reduced 是评审工具，不是官方服务的技术设置页。

一个 owner 管理每个节点/属性；快速反向从可见值和速度继续。过时异步结果以 epoch 拦截；切换目标/服务/账号和销毁时取消定时器、RAF/WAAPI、observer、listener、gesture capture，清空闭包对已移除节点的引用。开发 StrictMode 重复 setup/cleanup 不能重复发请求、提交、收件或回执。动画完成、unmount、超时都没有业务提交权限。

操作立即可用，不等待入场完成；关闭时背景语义、焦点恢复和 DOM 清理有确定路径，不依赖 transitionend。键盘焦点与hover同等明确，不让触控依赖hover。离屏、隐藏、暂停预览均停止活动循环，恢复只在当前状态仍需要时继续。演示浮层只在组件预览区内隔离并捕获焦点，F6返回评审控件；这不是生产整页 dialog 的最终无障碍实现。

## 接入和工程验收

原型只演示共享运动原语，所有结果来自明确fixture，不访问API、剪贴板、文件内容或设备权限。不可把109项挂载检查当作109个真实业务集成。

采用后先做共享 Web/Flutter owner 和已验收 v20 的控制/节点/浮层，在对应实际功能单元接入账号、跨用户、文本与离线队列。依次验证真实 React StrictMode setup-cleanup-remount、Flutter dispose/cancel、快速连按/反向、多指/拖拽、失焦/后台、系统减少动态效果、键盘/IME、不同字体/语言、真实账本/权限/超时竞态及低端设备/大列表性能。测试在 Fedora；真实设备手势和可访问性另有设备验收，未测不声称60fps。
