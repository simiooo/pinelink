# Pinelink 16 · 曲线进度与按需详情

2026-11-01。沿用已认可的 Meta 风格、Segoe UI、白灰界面与 primary `#0866FF`。本版根据最新反馈取消主界面的详细进度块，取代 14/15 版传输活动段规则。

主界面仅保留两个节点、一条 3px 曲线。蓝色是接收端已确认的字节，灰色是剩余字节；蓝色按真实弧长从发送端向接收端增长。没有常驻百分比、文件名、大小、速度、ETA 或操作栏。传输时在蓝色范围内部播放柔和流光，蓝色终点仍只由真实字节推进。暂停保留蓝色长度并移除流光，未知总量保持灰线；必要的短状态仍可出现。

点击曲线（24px 指针命中范围）或任一传输节点打开详情；键盘通过原生节点按钮打开同一视图。PC 使用 400px modal，padding 24px；手机使用全宽 bottom sheet，padding 20px，顶端 handle。数字、文件名、速度/ETA、暂停/继续和取消仅在此出现。取消需要确认，关闭详情保持传输。

## 动效和真实数据

- 蓝色弧长 ≤180ms 追到样本值，不超过确认量、不循环。数字立即更新，不补间生成未确认字节。
- 仅 RUNNING 且已有确认字节时，`#80B1FF` 柔和高光在已完成的蓝色内沿传输方向走一遍，1600ms、3px、最长为整条路径的 6%。高光被确认弧长 mask 裁切，灰色区始终不受影响。暂停 80ms 淡出并停止，继续 120ms 淡入；校验、终态、页面隐藏与减少动态时不播放。OpenPencil 11 页附 Active / Paused / Reduced 对照板。
- 桌面详情进入 180ms / y 8→0 / scale .98→1，退出 120ms；手机进入 240ms / y 24→0，退出 180ms。背景 opacity .13，遮罩 .06。
- 100% 只表示字节确认量达到总量。收到校验/回执后才显示 Delivered / Received；云封存显示 Stored in cloud。
- 减少动态时取消位移、缩放和弧长补间，保留静态真实进度。关闭详情不会改变任务；迟到样本不能覆盖终态或倒退蓝线。
- 速度/ETA 使用稳定有效样本；暂停、恢复后重新采样或数据过期时收起。不以响应到达时间冒充字节观测时间。

后端缺口与架构修订见 [传输进度与交互契约](../../infra/docs/transfer-progress.md)，参数在 `progress-motion.json`。应用实现需在设计验收后接入；本轮没有修改或部署应用代码。

## 验证

`check-16-progress.cjs` 检查主图无详细数字、蓝色弧长、曲线实际点击、键盘入口、详情关闭、暂停/继续、取消确认、乱序样本、100% 与回执、未知/空文件、批量聚合、接收方向、减少动态、原生拖拽，以及 320/390/736/1024 布局。结果写入 `motion-verification.json`。
