# Device conversation v42

This OpenPencil update replaces the device's separate send and history actions with one conversation action. The conversation keeps files and text in the same timeline and places attachment selection, a sensitive-text switch and send in the input group. An attachment is previewed in the composer; a file and a valid text draft can be sent together. The sensitive switch applies to text, not to a file.

The `.fig` was generated and reopened with OpenPencil core. The rendered frames cover 320 px and 390 px device actions and conversations, a selected attachment, and the desktop panel. This is a design review artifact, not a claim of a running implementation.
