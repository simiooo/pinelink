# Pinelink 完整功能与验收矩阵

本矩阵按实现与真实调用验收，不把“有表、有接口、有关闭开关”视为完成。各项均已实现，并由 `infra/scripts/integration.sh` 中的对应成功、重复、并发、冲突、过期或恢复场景验证。

## 接收端与通知

- [x] 在线通知接收、主动查询未处理通知、断线后事件游标补拉与权威快照校准。
- [x] 接受、拒绝、发送方取消；重复响应幂等，过期请求不可接受。
- [x] 未接受不能拉取；取消或拒绝后已有拉取不能继续。
- [x] `ONLINE`、`ASYNC`、`BROADCAST` 交付语义及广播逐接收者状态。

## 任务控制与历史

- [x] 上传和下载均有稳定任务 ID、状态版本、真实进度和异常原因。
- [x] 暂停、继续、取消、删除任务；运行中的 CLI 能感知控制动作。
- [x] 续传保持原任务/拉取身份；重复下载创建新 PullSession，不覆盖首次交付回执。
- [x] 按状态、类型和时间查询历史，删除仅影响默认可见性，不抹掉审计事实。

## 一致性异常

- [x] 所有控制动作使用 `expected_version`，状态冲突返回当前权威快照。
- [x] 另一端取消、权限撤销、文件过期/删除、服务端状态变化会中断相关传输。
- [x] 重复、乱序事件不导致状态倒退；客户端按事件游标补拉并可从快照恢复。
- [x] 下载内容根、长度和分块校验失败不会生成完成文件或交付回执。

## 存储与生命周期

- [x] 中继暂存与在线交付分别确认；只有 `SEALED` 可离线拉取或提升。
- [x] 免费完整副本保留 24 小时，未完成副本最后活动 24 小时后清理，拉取不续期。
- [x] 临时副本提升持久化：授权、配额、保留锁、完整校验、崩溃恢复。
- [x] 逻辑引用与物理版本分离，物理配额、最后引用宽限期和幂等垃圾回收。
- [x] 限定安全域/加密域整文件秒传、上传会话分块续传、跨域不泄露存在性。

## 安全与网络

- [x] 用户、设备身份、设备加入/撤销和每次控制/拉取授权。
- [x] DARE 应用层 E2EE、age/X25519 加密 manifest、多接收者密钥封装；服务端无明文和可用内容密钥。
- [x] Pion WebRTC 内网/公网直连、候选优先级、可配置 STUN/TURN，开发 Compose 含 coturn。
- [x] 应用中继分别终止两条 WebRTC 连接，只处理密文并可 tee 到 S3；会话级租约防止多实例串流。
- [x] 同一会话直连与中继迁移，分块去重、进度连续、不伪造完成；中继可从 S3 恢复下行缓存。

## 表现与 CLI

- [x] 默认任务投影不暴露路径切换，真实异常不被动画掩盖。
- [x] CLI 覆盖发送、通知、接受/拒绝、上传、下载、暂停、继续、取消、删除、历史、广播、持久化和设备密钥。
- [x] 全功能 Compose 集成测试同时覆盖成功、重复、并发、冲突、过期和恢复路径。

## Web 与 Flutter UI（SIM-840）

- [x] OpenPencil 桌面/移动逐页稿、角色三视图、九动作契约和静态交互流程稿；全部 lint 为 0 errors、0 warnings。
- [x] TanStack Web 与 Flutter 共用信息层级；首页/通知/任务主屏操作不超过三个，次要操作进入“更多”。
- [x] 真实通知查询、接受/拒绝、版本冲突刷新、任务暂停/继续/取消、历史筛选与逻辑删除、设备与容量查询、文件保管提升。
- [x] Web 14 组测试及构建；Flutter 23 组测试（含中英文真实渲染图像）、分析及 Web/Android 构建；系统减少动态效果有静态终态。
- [x] `zh-CN` / `en-US` 全界面国际化，系统语言协商、运行中语言变化、更多菜单切换及 `pinelink.locale` 偏好持久化。
- [x] 真实 CLI 加密上传、界面长期保存、同一终端两次完整下载；两个 PullSession 不覆盖首次交付回执，明文逐字节一致。
- [x] 容量按与 CLI 相同的作用域读取；`encrypted` 隐私占位符不冒充明文文件名。
- [ ] Web/Flutter 原生 WebRTC、DARE、age 数据面与设备签名身份引导；本轮发送准备只生成真实 CLI 命令，不宣称已在界面内发送。
- [ ] OpenPencil 点击式页面原型；v0.16.0 的 `reactions` 回读为空，当前只验收静态流程稿与双端真实交互，未把伪链接算作完成。

生产部署仍需独立安全评审、公网 NAT 环境验证、容量与压力测试；这些环境验收不作为未实现功能的替代说明。
