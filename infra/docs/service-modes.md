# 官方服务与自定义服务

2026-11-02用户确定：Pinelink采用Apache-2.0开源；所有客户端默认连接官方服务 `pinelink.sqmem.top`，用户可使用自己的服务。官方模式没有技术配置界面，自定义模式按高级用户设计。OpenPencil补充稿在`designs/22-service-modes`，尚待验收，不代表运行客户端已经支持切换。

## 入口与信息层级

首次启动直接进入设备图，不出现选服务器、填URL、owner/device、密钥、STUN/TURN或存储的引导。官方地址、信任根、信令与网络策略由受信配置管理；设备身份自动建立，不将dev-owner/dev-scope等开发占位值固定到公开包。

“连接自己的服务”放在更多菜单；官方模式中没有可编辑的服务面板。用户主动选择该入口后，进入自定义草稿：先填服务地址，再按需展开高级项。桌面使用轻浮层，移动端使用独立全屏页面；密集字段左对齐。PC面板横向24、纵向28/32px，移动端横向20px，字段标签到输入8px，功能组24/32px，触控48px。桌面容器按内容取高度，最后一组到主按钮32px；恢复官方服务入口单独保留48px操作行。

自定义模式提供服务地址、服务身份/指纹、信令地址、ICE服务器与传输路由偏好。默认沿用服务器声明的能力；服务不支持的项不伪造可用。客户端不接收数据库、S3主密钥等部署管理凭据。身份/认证方法须由对应服务器支持，不能凭空添加当前后端不支持的token字段。

## 首次连接与切换

1. 编辑草稿期间，当前官方/自定义会话仍然有效；不把草稿URL写成运行地址。
2. 对目标读取有界、无旧会话凭据的能力/身份探测；验证签名、兼容性和HTTPS。首次自定义连接显示完整SHA-256指纹供核对；明确确认后保存信任。后续身份改变不能静默信任。
3. 有活动传输时先提供“留在这里”或“暂停并切换”。等待可恢复传输的持久checkpoint；失败保留旧会话，不谎报暂停。不支持安全暂停的任务必须结束后切换。
4. 排空旧worker/订阅/请求，使用代次隔离迟到回调；原子激活新profile并重建查询缓存和视图。旧身份、token、密钥信封与URL授权不发送到新服务。
5. 每个服务按规范化地址、账户/设备和信任代次隔离身份、凭据、缓存、同步游标和传输记录。不同服务器的transfer ID相同也不能混用；旧任务不会被迁移到新服务器。回到旧服务后从旧账本恢复。
6. 自定义已连接后才提供可编辑配置与“使用Pinelink”恢复入口。恢复官方服务使用内置受信profile，保留但不携带自定义凭据，不出现官方配置表单。

Web的Service Worker也属于同一切换事务：按活动profile与信任代次校验后台任务，撤销或排空旧服务同步，不能在前台切换后继续按旧构建常量向旧服务提交。当前自定义服务切换尚未实现；PWA背景同步只消费当前构建对应的隔离库。

切换失败不自动回退到另一个服务器。官方不可达时，本地已配对设备的离线直传仍应工作，不因云配置失败禁用LAN。浏览器的混合内容/CORS限制如实显示短错误，不提供跳过证书验证的开关。

## 动效与可访问性

桌面浮层160ms、移动页面220ms，低幅度淡入/位移；关闭逆序，焦点回到更多菜单入口。测试连接时按钮保持尺寸并显示小型活动标记；失败保留已输入内容。切换操作先显示真实等待状态，收到checkpoint后才完成。减少动态效果时立即切换，不播放流光。所有图标操作提供可访问名称、键盘焦点和tooltip。

## 发布前依赖

- 正式服务域名已确定为 `pinelink.sqmem.top`；正式HTTPS/TLS、受信配置、客户端自动身份引导和官方账户/设备授权策略仍需实现和验证。当前开发注册能力不能被当作公共官方服务的完整账户授权，也不能直接把staging开发默认值改成正式URL后发布。
- 自定义配置验证、profile隔离、活跃任务切换和失败回滚必须先通过验收，再移入Web/Flutter/CLI；现有SDK关闭与缓存竞态修复可复用。
- 公开客户端不能使用staging地址或共用开发身份。官方/自定义的区别是产品入口与配置策略，不是隐瞒开源代码中的可见地址，也不是安全边界。
