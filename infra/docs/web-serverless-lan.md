# Web/PWA 无中心服务的局域网收发

此路径不向中心注册访客，不使用中心配对、WebSocket 信令、外部 DNS、STUN、TURN 或云副本。两端需在可互通的局域网中；访客和账号的既有联网传输路径仍独立保留。

## 使用

1. 两台设备打开 Pinelink，添加设备，选择「本地」。一端创建连接，另一端扫码、导入 `.pinelink` 文件或粘贴连接包。
2. 第二端生成回复，第一端扫码、导入或粘贴回复。首次连接在两端核对六位号码并分别确认；单方确认不会保存配对。
3. 选择文件，接收端明确接收后开始传输。节点图只显示两个设备和一条线；蓝色表示接收端持久化确认的密文字节，详情中查看暂停、恢复与取消。
4. 断链或关闭浏览器后保留本地身份、配对、密文与确认量。重新交换连接包，以已固定的完整公钥验证设备，然后继续同一传输。不会在无外网时尝试上传云端。

连接包两分钟后失效，已使用的邀请不能再次建立新连接。双方的设备时钟无需一致；邀请和文件使用各自的相对有效期。默认文件有效期十分钟，单文件上限 64 MiB，最多两个活动传输。

## 第一次完全离线启动

已安装且完成缓存的 PWA 可在原 HTTPS 地址离线重开。未取得过网页资源的设备无法凭空加载网站。

桌面离线包包含匹配版本的 CLI 和 `web/` 静态资源。解压后运行附带的启动脚本，或：

```sh
pinelink local-web --web-dir web
```

启动器只监听 `127.0.0.1:17643` 并打开浏览器。这是本机网页资源入口，不代理中心 API，也不提供用户文件系统或密钥接口。固定端口保留同一浏览器 origin 的本地身份；更换端口、浏览器配置文件、站点来源或清除站点数据都会得到另一个本地空间。关闭终端会停止资源服务，浏览器已缓存的页面仍可离线使用。

手机使用预先安装的 PWA 或原生应用。不能将桌面启动器改为普通局域网 HTTP 地址并假定手机仍可使用摄像头、加密 API 和 Service Worker。

## 浏览器发现与原生发现的区别

浏览器没有通用的任意 Bonjour/mDNS 扫描接口。此处用双方显式交换的签名连接包发现目标，WebRTC 再在本地选择可达的 host/prflx 候选；浏览器内部 ICE 的 mDNS 名称解析不等于应用能够枚举局域网设备。

原生 CLI 的 `lan discover/serve/pair/send/accept` 复用已有 Bonjour、本地 TLS、短期邀请与 SQLite 权威日志，见[原生离线契约](offline-local-delivery.md)。Flutter 界面适配另行交付，不能以 CLI 或浏览器测试代替 Android 实机能力。Web 本地协议目前只支持浏览器间收发；与原生 TLS 数据面的互操作需要原生适配或明确的局域网 HTTPS 桥接，不能混称已完成。

AP 客户端隔离、访客 Wi-Fi、VPN、操作系统防火墙或浏览器的局域网权限都可能阻止对端候选互通。允许本地网络访问并使用可互通的网络后，重新连接。此离线路径不会静默改为云中继。

## 身份、控制与完成条件

- IndexedDB 使用独立的本地 Ed25519/AGE 身份，和云账号、访客租约分开。首次号码核对绑定双方公钥、完整 SDP 与回复；已配对设备固定完整签名和加密公钥。
- `PL2:` 连接包使用有界 deflate 和适合二维码的 Base45；兼容读取旧 `PL1.`。解压总量、SDP 大小和候选内容均有上限，仅接受一个 data-only SDP。连接包含私网连接信息，应只交给拟连接的设备。
- DataChannel 使用浏览器原生 DTLS/SCTP，AGE/DARE 文件密文复用现有加密实现。应用控制消息另有域分离签名、连接 transcript 和严格单调序号。
- 接收端是 `LOCAL_DEVICE` 权威。分块、确认量、签名状态和增量日志在同一 IndexedDB 事务提交后才 ACK。发送端字节计数不冒充持久化进度。
- 只有全量密文哈希、解密与明文哈希均通过，并原子保存明文与接收端签名回执，才进入完成状态。发送端验证该回执后才能显示送达；没有云端「已保存」状态。
- 暂停/取消/过期递增控制版本，旧版本帧与校验提交受栅栏保护。取消清理部分密文，不产生完成回执。发送端断链取消只保存待发送意图，不能伪造接收端状态。
- Web Locks 与带所有者/连接标识的 IndexedDB 租约限制同一设备对的写入者。新标签页不能接管仍活跃的连接；崩溃重开可重新获取锁与恢复持久化检查点。
- 本地日志保留本地权威和签名，不把 `local:` 记录投到中心 UUID 接口，也不伪造中心回执。此单元不声称新增的浏览器本地记录已接入中心三方复制；已有账号复制保持原路径。

## 验证

生产构建后，在 Fedora 使用两个独立浏览器进程和网络命名空间运行：

```sh
python3 infra/scripts/test-web-direct.py \
  --source "$PWD" --output "$PWD/.artifacts/offline-check" \
  --browser-cache /path/to/playwright-cache \
  --go-toolchain /path/to/go --go-mod-cache /path/to/go-mod \
  --go-build-cache /path/to/go-build \
  --serverless --standalone --cases full
```

浏览器首次从真实 `local-web` 启动器加载，之后内核禁止公网、中心、外部 DNS 和网页源站连接，仅允许对端、mDNS 与测试控制器。测试不替换 ICE、证书或 DataChannel：覆盖首次配对、屏幕二维码解码、16 MiB 与空文件真实下载哈希、拒收、暂停、第二标签页冲突、断链/刷新重连续传、取消和校验竞态、重放、摄像头不可用与离线历史。测试用二进制发送闸门只用于确定暂停/取消时间点，网络断开由容器内核执行。Firefox 通过 `--browser-b firefox --firefox-cache /path/to/cache` 验证互操作。实际结果和部署版本以对应交付记录为准。
